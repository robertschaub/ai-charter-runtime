# Agent rules — ai-charter-runtime

The authoritative working rules for AI agents and humans in this repository. The tool wrappers — [CLAUDE.md](CLAUDE.md) and [.github/copilot-instructions.md](.github/copilot-instructions.md) — point here; if they ever diverge, **this file wins**.

- **The spec is authoritative.** Build to [runtime-gates-poc-spec.md](https://github.com/robertschaub/our-ai-charter/blob/main/docs/wip/runtime-gates-poc-spec.md) (mirrored on the [site](https://robertschaub.github.io/our-ai-charter/wip/runtime-gates-poc-spec/)); on divergence the spec and its linked Charter sources win. Spec changes happen in `our-ai-charter`, never by silently drifting here.
- **Licensing is per-directory** — [LICENSE.md](LICENSE.md) is the map; every source file carries a matching `SPDX-License-Identifier` header. Do not move code across the AGPL/MIT boundary without updating the map.
- **Honesty rules:** this is a maintainer sketch, not a certification artifact ([NOTICE](NOTICE)). No green-light surfaces, no "queryable certification", no claims of independent assurance. Test-family coverage is marked exercised / partial / not assessed — never implied.
- **Public repository boundary.** Treat this repository and every commit as public and permanent. Apart from the public Charter/spec sources linked above, stay within this repository unless the maintainer explicitly names an external repository or path for the current task. Do not read, import, or summarize private-repository material, and never disclose private repository names or paths, secrets, real personal data, or other confidential records in this repository or another public artifact. Public documentation links only to public URLs and files and must not depend on local paths or unpublished context. If the boundary is uncertain, ask before crossing it.
- **Secrets and test data:** keys live only in gitignored `.env.local`; never in code, logs, fixtures, records, or probe output. Fixtures and tests use synthetic data only; never use real personal data.
- **Git & safety:** work directly on `main`; the maintainer decides when to push. Conventional commits (`type(scope): description`). When loaded and trusted, the shared **PreToolUse hook** ([.claude/settings.json](.claude/settings.json), mirrored in [.codex/hooks.json](.codex/hooks.json)) screens destructive Git forms including hard resets, non-lease forced pushes, forced cleans, and broad checkout/restore discards. Hook coverage is a backstop, not a guarantee — it may be untrusted, skipped for some tools, or absent in subagents — so never delegate destructive git to a subagent; keep it in the main session or do it by hand. To undo, prefer a revert commit.
- **Verification and stateful tooling.** Normal local checks are `npm run typecheck`, `npm test`, and, for model-card changes, `npm run cards:verify`. Explicit maintainer approval is required before `npm run probe` or direct `tooling/probe.mjs` calls, which contact external model APIs and write probe results; before `tooling/keys.mjs generate|rotate-hmac|gen-card-keys`; and before `tooling/cards.mjs sign`, which changes signed public artifacts and may change the trust root.
- **GitHub posture** (applied 2026-08-01 at repo creation; adapted from the sibling repos): visibility **public**; human repository access is limited to the maintainer account, with no collaborators, deploy keys, or webhooks. The OpenAI Codex GitHub App is the sole explicitly approved exception and currently has access to this repository; treat it as write-capable, keep its repository selection minimal, and remove it when no longer needed. No additional GitHub Apps or integration-scope changes without explicit maintainer approval. Secret scanning + push protection, Dependabot alerts, and private vulnerability reporting are **enabled**; `main` is protected against force-pushes and deletion. GitHub Actions are restricted to what the repo actually needs (none yet — add deliberately, never copied wholesale from FactHarbor). Public issues stay open for feedback, but gate-bypass and record-integrity findings go through the private route in [SECURITY.md](SECURITY.md), and spec questions belong in `our-ai-charter` ([.github/ISSUE_TEMPLATE/config.yml](.github/ISSUE_TEMPLATE/config.yml) routes both).
- **Records are part of the system under test**: never hand-edit files under `records/`; tamper tests do it deliberately via the test harness.
- **Platform:** Windows — use PowerShell-compatible commands (`$env:VAR`, `$null`, backtick continuation). Node ≥ 20, ESM; LF line endings enforced by [.gitattributes](.gitattributes).
- The gate invariants are non-negotiable in code review: model output never authorizes; a signal has no code path to allow; ambiguity or missing authority fails closed; the orchestrator reaches no authority-changing endpoint; every consequential effect requires a valid single-use commit token.
